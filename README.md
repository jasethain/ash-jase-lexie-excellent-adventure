# Ash, Jase & Lexie's Excellent Adventure V2

Hello Kitty inspired Japan travel companion for iPhone/iPad, built as a Vite app for GitHub + Vercel like Happy Little Bubbies.

## Deploy to Vercel
1. Upload all files in this folder to the GitHub repository.
2. In Vercel, import the repository.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## iPhone/iPad access
Open the Vercel URL in Safari, tap Share, then Add to Home Screen.

## Included features
- Apple Maps links and offline setup guidance
- Offline AUD/JPY converter using last known rate 1 AUD = 112.905 JPY
- Lexie's location-style journal and treasure hunt
- Lexie plain-food mode
- Jase/Ash vegetarian mode
- Japanese phrase speaker and visual-translation workflow
- Offline-first PWA service worker
- Booking wallet assets

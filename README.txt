Ash, Jase & Lexie's Excellent Adventure - Offline-first iPhone/iPad travel app

How to use on Apple devices:
1. Upload this folder/ZIP to a simple web host, or open locally for testing.
2. On iPhone/iPad, open index.html or the hosted link in Safari.
3. Tap Share > Add to Home Screen.
4. Open the Home Screen app once while online so offline files cache.

Includes:
- Hello Kitty inspired animations and theme
- Apple Maps links and offline setup guide
- Lexie's location-aware style journal, treasure hunt and plain food mode
- Jase/Ash vegetarian mode
- Built-in offline phrase translator cards with Japanese speech where supported
- Visual translation scrapbook area
- Offline AUD/JPY converter using last known rate 1 AUD = 112.905 JPY
- User-entered notes, custom info and photo uploads stored locally on the device

Limitations:
- Apple/Google map data cannot be bundled legally inside the app. Download Apple Maps offline areas separately.
- Full arbitrary visual/voice translation requires Apple Translate/Camera or another translator app; this app includes practical phrase cards, speech playback and saved visual translation notes.
